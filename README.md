# 🛒 Análisis de Ventas y Rentabilidad de Supermercado

## 🎯 Objetivo del Proyecto
Análisis exploratorio de datos históricos de un e-commerce ficticio para identificar productos rentables, segmentar clientes clave y evaluar la salud financiera del negocio a lo largo de 4 años.

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Python
* **Librerías:** Pandas (limpieza y manipulación de datos) y Plotly (visualización interactiva)
* **Entorno:** Jupyter Notebook / Google Colab

## 📊 Conclusiones Principales (Insights)
1. **Motor del negocio:** La Tecnología es la categoría con mayor beneficio neto.
2. **Fuga de rentabilidad:** Los muebles (Furniture) generan un gran volumen de ventas pero márgenes de beneficio mínimos, lo que indica una necesidad urgente de revisar los costes logísticos.
3. **Cliente ideal:** El 50.6% de los ingresos provienen del cliente particular (Consumer), superando ampliamente al sector corporativo.
4. **Salud general:** El negocio muestra un crecimiento sólido y sostenido en ventas.
